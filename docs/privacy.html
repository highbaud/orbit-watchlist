Privacy policy

Effective 15 August 2026. Last updated 16 August 2026.

Orbit Watchlist is a Chrome extension for local crypto watchlists. It does not collect, sell, or share personal data. There is no Orbit account and no Orbit server.

Data Orbit handles

Orbit handles provider API keys, watchlist names, provider asset IDs, cached market quotes, refresh times, and display settings, and only when you choose to provide or create them.

Watchlists and quote caches stay in Chrome extension storage. API keys stay in the browser session. If you turn on Remember this key, Orbit encrypts provider keys with AES-256-GCM using a passphrase-derived key before storing the ciphertext locally. Orbit does not store the passphrase.

Network requests

While the popup or side panel is open, Orbit can send requests to the provider you selected: the CoinGecko Demo or Pro API, or the CoinMarketCap Pro API. Requests use the API key you supplied. Orbit does not send your key to an Orbit server, and Orbit has no Orbit server.

Orbit does not make market-data requests while the popup and side panel are both closed. It does not run background polling.

Permissions

  • storage saves local settings, watchlists, the quote cache, encrypted vault ciphertext, and session-only unlocked keys.
  • sidePanel opens the full watchlist manager after your click.
  • Optional provider host permissions allow requests only to the provider API you connect.

Orbit does not use content scripts, browsing history, page content, tabs access, ads, analytics, tracking pixels, or cloud sync.

What Orbit will never ask for

Orbit will never ask you to connect a wallet, enter a seed phrase or private key, sign a transaction, provide a wallet address, or supply an exchange API key, including one marked read-only.

This is a design constraint rather than a policy promise. Orbit holds nothing that could authorize moving funds, so even a full compromise of the extension cannot cost you an asset.

Your choices

You can remove watchlists, clear cached quotes, lock keys, or reset the vault from Settings. Uninstalling the extension removes its Chrome extension storage according to Chrome storage behavior.

Changes to this policy

If the data Orbit handles changes, this page is updated before the change ships, and the change is described in the extension itself. The version of this policy that applies to a release is the one published here on that release date.
