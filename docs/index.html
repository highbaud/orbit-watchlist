Orbit

A crypto watchlist that never asks for your wallet.

Orbit Watchlist is a Chrome extension for checking prices and keeping lists. It runs on your machine, uses an API key you supply, and has no account, no server, and no way to touch your funds.

In development, not yet published

What it does today

  • Named watchlists. Create, rename, reorder and switch between as many as you want. Each list is bound to one data provider so asset IDs never get mixed up.
  • Prices where you work. A toolbar popup for a quick look, and a Chrome side panel for managing lists while you browse.
  • Your own API key. CoinGecko Demo, CoinGecko Pro, or CoinMarketCap Pro. The key is checked with the provider before it is saved.
  • Real key protection. Turn on Remember and the key is encrypted with AES-256-GCM using a passphrase-derived key. The passphrase is never stored.
  • Honest data. Every quote shows its exact update time, and stale figures are labeled instead of being passed off as current.
  • Bulk import that asks. Paste a list of coins and Orbit reports each line. When a ticker matches more than one asset it makes you choose rather than guessing.

What it will never do

NEVERConnect a wallet, read a seed phrase, hold a private key, or sign a transaction.
NEVERAsk for a wallet address, including a watch-only one.
NEVERAsk for an exchange API key, including one marked read-only.
NEVERUse Chrome sync, analytics, tracking, or advertising.
NEVERSend your data anywhere except the price provider you chose.

These are not settings. They are the architecture. Orbit holds nothing that can authorize moving funds, so even a total compromise of the extension cannot cost you an asset.

Why you can check this rather than trust it

Every crypto tool claims to respect your privacy. Almost none let you verify it. Orbit's source is public, and the whole extension makes network requests through exactly one function, so anyone can read what leaves the machine in a few minutes.

The permission list is deliberately tiny: storage, sidePanel, and access to the one provider API you connect. Nothing else. A short permission list is also the thing that makes any future change obvious.

Who made it

Orbit Watchlist is built by Max Avery, who writes about digital assets, illicit finance, and Web3 security. It grew out of wanting a price check that did not require handing an account or a wallet to anyone. Made with support from DAG.
