# Load Orbit Watchlist in Chrome

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Click Load unpacked.
4. Select the `dist` folder in this project.
5. Click the Orbit Watchlist toolbar icon.
6. Choose CoinGecko or CoinMarketCap, add the provider key, and grant the provider permission when Chrome asks.

The build is local and uses the provider key you supply. Use Settings to lock or reset keys.

The extension needs Chrome 116 or newer for the side panel API.
